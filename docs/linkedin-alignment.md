Prioritize JavaScript, TypeScript, React.js, HTML5, CSS3, Tailwind CSS, Vite, Node.js, Express.js, REST APIs, PostgreSQL, SQL, Git, and GitHub. Add Policy-as-Code, testing/debugging, technical documentation, security/privacy awareness, and responsible-AI awareness as supporting skills only where LinkedIn’s skill taxonomy allows and the profile context explains the evidence.

## Suggested banner direction

Use a warm neutral background with deep ink typography and a restrained emerald accent. A simple editorial engineering motif—an abstract policy decision path, typed data flow, or small grid of inspectable states—will align with the portfolio without using neon gradients, stock imagery, or generic AI visuals. Keep the banner text short: **“Software Developer · JavaScript & TypeScript”**.
