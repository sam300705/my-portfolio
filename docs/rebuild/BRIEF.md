## 8. TECHNICAL ARCHITECTURE

The preferred modernization stack is:

- Next.js App Router
- TypeScript in strict mode
- SCSS Modules and CSS custom properties
- GSAP and ScrollTrigger for intentional animations
- Next.js font and image optimization
- Semantic HTML and accessible React components
- Playwright for browser-level regression testing

Evaluate the existing architecture before committing to a migration.

### Advanced effects

Consider these only when they materially improve the experience:

**Three.js / React Three Fiber:** for one meaningful, optimized interactive visualization rather than generic decoration.

**GLSL:** only if a specific shader effect is justified and can be implemented efficiently.

**Lenis:** only if it demonstrably improves motion without impairing native scrolling, keyboard navigation, touch behavior, or performance.

**Motion for React:** only for interactions that would otherwise be unnecessarily complex. Avoid duplicating responsibilities across animation libraries.

Use dynamic imports and code splitting for heavy client-side components.

Keep most narrative and content sections server-rendered or statically generated.

Avoid unnecessary backends, databases, authentication, analytics, and dependencies.

Use a simple, working contact method unless a contact form is independently justified.

### Engineering standards

Maintain a clear component structure, reusable tokens, typed project content, limited dependencies, no exposed secrets, and production-safe configuration.

Preserve the website's existing useful progressive enhancement and accessibility behaviors.

Do not introduce animation frameworks merely because they appeared in the reference video.
